# Personal Website

My repo for my [personal website.](https://Scarvy.github.io)

Plain HTML, CSS, and JavaScript — no build step. Deployed using [GitHub Pages.](https://pages.github.com/)

- `index.html` — about, links, and timeline
- `extra/` — resume and papers
- `css/style.css`, `js/main.js` — styles and theme toggle

Preview locally with `python3 -m http.server`.
